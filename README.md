# MDS 骨髓增生異常症候群 — NCCN v1.2027 臨床速查手冊

基於 **NCCN Clinical Practice Guidelines in Oncology: Myelodysplastic Syndromes (Version 1.2027, November 17, 2026)** 整理之繁體中文臨床重點與快速查找網站。

## 功能特色
- **章節快速導覽與全文即時搜尋**：支援 `/` 快捷鍵、關鍵字高亮、基因/藥物快速檢索。
- **v1.2027 重大更新整理**：NGS 醫療必要化、IPSS-R/IPSS-M 並列、新增 *UBA1*/VEXAS 治療路徑、Luspatercept 調整細則、Venetoclax blasts <5% 警語、IWG 2023 療效標準。
- **互動式 IPSS-R 計算機**：即時計算總分、風險分組、中位存活期與低/高風險治療路徑分流。
- **完整表格速查**：WHO 2022 / ICC 2022 分類、MDS/MPN 重疊腫瘤、29 個常見體細胞突變基因（支援分類篩選）、遺傳易感症候群 (HMMPS)、常用藥物劑量與排鐵治療。
- **深色 / 淺色模式切換**，支援桌面與行動裝置瀏覽。
